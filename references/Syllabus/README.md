# Syllabus files

One file per **class + subject + year**, named like:

```
class10-physics-2027.md
class9-math-2026.md
```

Syllabi change by year and by curriculum, so always put the year in the filename and note which curriculum the class follows. Copy `_TEMPLATE.md`, fill it from the official NCTB or board syllabus, and add the source link.

A student's own school syllabus (they may send a photo) always overrides these files, because schools often cut chapters for the final exam.
